# HTTP API reference

Generated by `python -m tools.export_sbp`. Exact field types, required fields, limits, defaults and error responses are in [OpenAPI](openapi.json) and [JSON Schema](schemas.json).

All routes require HTTPS. `B` is an administrator-provisioned bootstrap bearer; `S` is a session bearer. Agent-bound sessions are restricted to their agent. Additional role/scope restrictions are described in [SBP](specification.md).
