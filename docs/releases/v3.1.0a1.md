# Super-Bot Alpha 2 · 3.1.0a1

Changes since the [previous public alpha](https://github.com/displaynameroblox/super_bot/releases/tag/alpha), which shipped Python package `2.1.0a1`.

## What's new

- **Discord and shared Miso memory.** Link a Discord identity from the TUI to use the published Miso profile and recall in its linked private DM. Guest DMs and configured guild channels retain scoped history.
- **Managed integrations.** Start the HTTPS chat node, its Minecraft SBP bridge, and the optional Discord gateway with the server manager. Start Minecraft separately with the Java mod installed.
- **Platform-aware continuation.** Supported short invitations and `/handoff discord` or `/handoff minecraft` check the available platform evidence and offer the next step. Sending a message on another platform and joining a world are separate operations.
- **Diagnostics.** Use `doctor` for node checks and `debug platforms`, `debug prompts`, or `debug trace --last` for routing diagnostics. `debug test handoff --dry-run` exercises simulated platform readiness without a model.
- **Roblox closed test.** Enable the bridge for an approved player in a private test experience. Access is scoped to the grant and explicitly shared notes.

## Install and upgrade

Use the [server administration guide](../server-administration.md) for fresh installation, signed development-channel updates, and rollback. Back up your existing data before upgrading. Use the [Miso integration guide](../miso-3.1.0a1.md) to configure and verify optional platforms.

The previous alpha documented Windows discovery and model-download failures and a Windows TUI crash when connecting to a Mac server. Those paths still need release-candidate retesting. A live signed GitHub update also needs verification with published artifacts.
