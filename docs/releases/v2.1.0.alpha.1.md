# Super Bot v2.1.0.alpha.1

First public alpha in the 2.1.0 series. Python package version: `2.1.0a1`.

## Included

- Local-first accounts, saved chats, profiles and knowledge on each client.
- Terminal and browser clients with encrypted, fingerprint-verified server connections.
- Server lifecycle, administration and signed update commands in `super-bot-manager`.
- Local model integration and optional cloud model providers.

## Compatibility and limitations

Linux and macOS work in maintainer testing. Windows does not work and is not
supported in this alpha. Specific OS versions and hardware are not yet documented.
Python 3.10 or newer is required. Models and optional training dependencies are
installed separately. This alpha may contain bugs; back up client data before
upgrading. Accounts and chat history do not automatically sync between devices.

## Install and use

Download `super_bot-2.1.0a1-py3-none-any.whl` from this release and follow the
[README installation and usage guide](../../README.md#download-and-install-ai-server-and-clients).
Activate your Python environment, configure `.env`, run `super-bot-server`, and
start `super-bot-web` or `super-bot` in another activated terminal.

Managed alpha updates use the development channel:

```sh
super-bot-manager source use official --channel development
super-bot-manager update check
```

Official managed updates require the signed artifacts attached to this release.
Keep the old environment and a private backup of client data when upgrading.
